          GUIDE / PRIVACY / LIMITS
          Getting started & support
          
 
          Which KiCad files should I open?
          Start with your actual .kicad_pcb. Include its matching .kicad_pro design-rule settings, an optional .kicad_sch root schematic, a hierarchy folder if it references child pages, and optional .kicad_dru rules. Missing project rules mean KiCad may report different findings.
          
 
          Does Review Studio modify my board or authorize manufacturing?
          No. It copies the source file into a private review workspace and runs KiCad on a separate snapshot. The original KiCad source remains unchanged. DRC and ERC findings, native copper plots, missing connections and library mismatches require independent engineering review. No project is approved for fabrication here.
          
 
          How do I back up and permanently remove my PCB data?
          For boards imported directly in this application, choose Export private ZIP backup on the review card first. The archive contains your native KiCad evidence and the local copies of the source PCB and any selected schematic/project files. Keep it secure: it may include confidential design data. To erase the local review and its copied source files, use Delete local review…, type DELETE, and explicitly confirm. The original design on your computer is not affected. Reviews registered from outside the application are deliberately not eligible for automatic deletion.
          
 
          Where are files saved and how do I stop?
          Installed application reviews live in your user data folder, usually ~/.local/share/zaptrace-review-studio/workspace. Closing the browser tab does not stop the local engine. Use Stop local Review Studio at the bottom of this page. Restarting the app preserves completed reviews. Uninstalling the package does not delete your saved engineering work.
          
 
          What systems and licenses are supported?
          Distribution 0.1.12 is built for Ubuntu 24.04 LTS with native KiCad 10.x and system Python 3.12. It uses the PolyForm Noncommercial 1.0.0 license; commercial use is not automatically licensed. Other operating systems and KiCad versions require separate validation. Run zaptrace-review-studio --doctor to inspect local dependencies.
