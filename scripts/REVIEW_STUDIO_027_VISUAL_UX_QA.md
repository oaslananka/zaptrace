# Review Studio 0.1.27 — true KiCad 3D inspectability and ERC severity

**Unsigned local QA candidate, not a fabrication or release decision.** Exact 0.1.26 automated Chrome/Ubuntu/KiCad acceptance passed, but manual screenshot and Chrome geometry analysis identified two real UX failures on the same package. This immutable new candidate fixes those without altering source KiCad geometry, ERC/DRC result counts, real physical route status, original project bytes, or human safety gates.

The old 3D UI floated the expanded source model audit over the actual board: its `getBoundingClientRect()` intersected 100% of the original 342×228 pixel model viewport at 390px and ~33% at desktop 1440px. The new source-backed 3D mode reserves an explicit camera/model-inspection dock (while retaining all 8 KiCad orbit frames), adjusts viewport fit to both toolbar and the *actual open model-panel height*, and refits after the disclosure toggles. Desktop has a bounded taller canvas; mobile keeps a scrollable, reachable control dock below an unobscured model. Real headless Chrome checks the model-and-controls rectangle intersection, source model completeness warning, available orbit frames, no page horizontal overflow, and original source SHA at 320, 381, 390 and 1440px. It must find **zero overlapping pixels** without hiding the model audit or the original KiCad rendered geometry.

The source multi-sheet KiCad fixture has 0 ERC errors and 28 ERC warnings; previously the UI misleadingly rendered it critical-red. The new presentation reads the native severity fields as-is, reports `0 errors · 28 warnings`, uses warning amber (not error red), and labels the enabled-rule scope. Explicit negative browser checks confirm a simulated real error is critical-red, `not_run` is unknown rather than green, and unsupported/malformed counts do not appear approved. This is solely a display change, never an ERC waiver.

**Full product acceptance is still pending:** strict native physical DRC (16 unwaived rule violations), incomplete copper/PCB routing, missing 3D J1/U1 and TP1/TP2 links, independent physical UAT, state-hash-bound human review decisions (#31), KiCad live IPC (#30), routing quality (#35) and ESP32 strict sample qualification (#91).
