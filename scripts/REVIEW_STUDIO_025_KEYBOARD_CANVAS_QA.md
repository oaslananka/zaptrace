# Review Studio 0.1.25 — source-backend-safe PCB canvas keyboard audit

Native KiCad Review Studio is an engineering review product, not a full authoring PCB tool, and does not provide fabrication approval. The original real KiCad PCB currently renders **154** selectable footprint/pad/finding markers in a source-bound sample; forcing keyboard users to Tab through every marker is not a professional review flow. This candidate provides one Tab stop into the marker group, roving **ArrowRight/ArrowDown** (next source object) and **ArrowLeft/ArrowUp** (previous source object), plus Home/End and deterministic Enter/Space selection. Screen readers still see the individually named original objects; navigation is in source record order rather than synthetic spatial geometry. `Ctrl+K` object search, native DRC, original board identity, original coordinates and `fabrication_approved=false` are unchanged.

`tests/test_review_studio_025_canvas_roving.py` locks source behavior and `.deb` reproduction. Exact Chrome acceptance (320px / 390px / 1440px) checks only one focusable canvas marker, proper arrow focus, Enter performing original native DRC inspection, robust recovery when DRC markers hidden, inspector selection updating keyboard anchor without stealing toolbar focus, unchanged Ctrl+K and Escape, no page overflow and zero JS exceptions. This is an unsigned local prototype; real package and clean host acceptance must be separately rechecked before qualifying the release. Hardware DRC blockers and absent STEP models still exist.

The first unqualified local 0.1.24 `.deb` was not overwritten when the focused-marker-hide recovery was improved; it remains frozen as a superseded testing artifact and the revised candidate uses fresh version 0.1.25.
